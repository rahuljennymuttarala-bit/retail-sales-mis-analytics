# Retail Sales MIS & Analytics

A retail sales analytics project built using **Microsoft Excel, Power BI, DAX, and Python** to analyze sales performance, revenue trends, product performance, customer behavior, and key business KPIs.

## 📊 Project Overview

This project demonstrates an end-to-end sales analytics workflow, starting from raw retail transaction data through data cleaning, analysis, KPI development, and interactive Power BI reporting.

The objective is to transform raw sales data into meaningful business insights that can support management reporting and data-driven decision-making.

## 🎯 Business Objectives

- Analyze overall sales and revenue performance
- Track monthly and yearly sales trends
- Identify top-performing products and categories
- Analyze customer and regional performance
- Monitor key sales KPIs
- Identify growth and decline patterns
- Build an interactive MIS dashboard for management reporting
- Provide actionable insights from sales data

## 🛠️ Tools & Technologies

- **Microsoft Excel** – Data cleaning, preparation and analysis
- **Power BI** – Interactive dashboards and visualization
- **DAX** – Measures and KPI calculations
- **Python** – Data processing and supporting analysis

## 📈 Dashboard Analysis

The Power BI dashboard provides an interactive view of retail sales performance through:

- Sales KPIs
- Revenue analysis
- Monthly sales trends
- Product performance
- Category analysis
- Customer analysis
- Regional performance
- Comparative performance analysis

Users can interact with the dashboard using filters and slicers to analyze different business segments.

## 🧮 DAX Analysis

DAX was used to create analytical measures and KPIs such as:

- Total Sales
- Total Revenue
- Total Orders
- Average Sales
- Sales Growth
- Category Performance
- Product Performance
- Monthly Sales Analysis
